# PAW — Mia-side work, 2026-10-30

Mia-side results and the optimized build from October 30, 2026, pushed
at Christopher's word. This commit is purely additive: it touches no

`experiments/` notes and the root README.

## Architecture (his words, confirmed this day)

An MLP with ReflexStore augmentation. The four-neuron shape was a
demonstration, not the architecture. Learned material is weights, chunked
for portability across nets. The mechanism is offload on activation; the
read path is demand-driven pull when needed. The crux is keeping neurons
from saturating or dying.

## What is in this commit

- `chunk-test/` — chunk portability test (his order "Let's test that").
  Split verdict: cross-architecture reuse works on the same task (width-3
  chunk 0.978 vs random 0.789); cross-task transfer fails (chunk 0.778 vs
  random 0.833). "Use" means frozen chunks + trained readout, same input
  space only.
- `arch-test/` — architecture test, 20-problem audit, first-four
  corrections, saturation prevention, dead-neuron prevention. Headlines:
  offload preserves material exactly (oracle pull = upper bounds); centroid
  pull fails; MLP router fixes pull on digits (0.969/0.959/0.916, near
  oracle); reset wins for tanh saturation (0-2 units, zero learning
  cost); offload holds dead units at 0 in every config (his instruction
  confirmed mechanically); transfer works broad-source to related task
  only (+0.110); saturation's harm on digits is old-task retention, not
  continued learning.
- `cifar-test/` — the same architecture on CIFAR-10 (5 sequential binary
  tasks, grayscale 16x16, 256->128 tanh net). FAILS: pulled old-task mean
  0.193 vs baseline 0.651. Two causes: logistic router ~32% (near chance)
  and reset churn (5306 interventions, learn collapsing to chance).
- `paw-optimized/` — the optimized build (his order "Build paw but build
  it optimized"). Regular MLP + ReflexStore + MLP task router + throttled
  reset/death-offload (sustained 2-probe trigger, 5-epoch cooldown, 25%
  per-epoch cap; throttle values are Mia's empirical choices). Digits
  demo: pulled 0.972/0.968/0.930, saturation and dead counts at 0. CIFAR
  demo (1 seed): pulled old-task mean 0.619 vs baseline 0.651 — a real
  repair, not a fix. Router improves to 0.427 but stays the bottleneck;
  learn no longer collapses to chance but still declines; saturation
  climbs to 97/128. Deliberately not built: per-neuron reload from
  intervention chunks (his named next experiment), relevance-ranking
  pull, chunk pruning.
